# DR-016  臂間比較一律配對統計 + win count，不報 p 值
date: 2026-08-22    status: ACTIVE
context:   七臂共用同一組 seeds，未配對的 mean±std 會把 seed 間的共同變異算進
           雜訊，掩蓋一致的小幅差異（例：A4−A3 配對後是 −1.04±0.15 pp、0/5）。
options:   未配對 mean±std / 配對 + win count / 配對 + 顯著性檢定
ruling:    一律配對（同 seed 相減），報逐 seed 差值、配對 mean±std 與 win count。
           **不報 p 值** —— n=5 的政策沿用，顯著性檢定在這個樣本數下會誤導。
evidence:  outputs/exp2/main/EXP2.md（Paired comparisons 一節，四個指標各一表）；
           scripts/run_exp2.py::write_paired；commit 644b071
