# DR-044  Jaccard 隨機重疊參照統一為逐 slide 口徑
date: 2026-08-26    status: ACTIVE
context:   repo 裡並存兩套隨機參照口徑：
           - `run_exp2.py::arm_metrics`：先對該 task 的 slide 取平均 patch 數 n̄，
             再算一個值 f/(2−f)，f = min(K, n̄)/n̄ —— **task 平均 n 的單一值**（esca 0.00106）
           - `run_seqft.py` / `recompute_task_il.py::jaccard_reference`：
             每張 slide 各算一次再平均 —— **逐 slide 平均**（esca 0.00225）
           兩者相差逾兩倍。而**觀測的 Jaccard 本來就是逐 slide 算後平均**，
           參照卻用另一套口徑，並排在同一張表上會誤導讀者。
options:   (a) 維持並存並註明 (b) 統一為逐 slide (c) 統一為 task 平均 n
           ※ 本行由 Cursor 補上，PI 未原文指定選項清單
ruling:    (b) 統一為**逐 slide 算後平均**，與觀測值同口徑。
           改 `run_exp2.py::arm_metrics` 的 `jaccard_ref`，並重產所有含「隨機參照」欄的
           `EXP2.md`（main / order_main / ablation / ablation_bu0 / hier / hier2 /
           memory / memory_hier / prior / arch / verify_a1），每份表尾加一行口徑說明。
           論文只用逐 slide 口徑。
           ⚠️ **這改變了已發布報告的一欄數字**，故建卡記錄。
evidence:  改動前後的方向對照（`outputs/exp2/main/EXP2.md` A1 臂）：

           | task | 觀測 Jaccard | 舊參照（task 平均 n） | 新參照（逐 slide） | 方向 |

           | esca | 0.00000 | 0.00106 | 0.00225 | 低於（不變） |
           | rcc | 0.00050 | 0.00123 | 0.00220 | 低於（不變） |

           新值與 `outputs/exp2/seqft/TASK_IL.md` 早已使用的逐 slide 值一致
           （0.00225 / 0.00220 / 0.00186），兩份報告從此同口徑。
