# DR-027  批次腳本的失敗語意；字串替換必須斷言錨點
date: 2026-08-25    status: ACTIVE
context:   G1' 首次啟動時 run_exp2.py 因 NameError crash，但 g1prime.sh 沒有 set -e，
           照樣往下走並印出「=== G1' 完成 ===」。hier2/per_slide 為 0 份，
           整批未執行卻看起來成功。根因是字串替換的錨點不存在卻靜默通過 ——
           同類錯誤兩週內第二次。
options:   (a) 只修這次 (b) 立兩條規則：批次腳本的失敗語意 + 替換必須斷言錨點
ruling:    (b)。憲法 §3.5：所有批次腳本 set -euo pipefail；「完成」訊息只能在產物
           通過存在性檢查後印出；批次結束檢查預期產物數量（arms × seeds），
           不符即非零狀態結束並標示缺項。憲法 §2.7：字串替換前斷言錨點存在且
           次數符合預期、替換後斷言含新內容，錨點不存在必須失敗。
           **偽裝成成功的失敗比 crash 危險** —— crash 會被看見，前者不會。
evidence:  outputs/exp2/g1prime.log（整批未執行卻印完成）；
           tests/test_cli_entrypoints.py；docs/CONSTITUTION.md §2.7、§3.5
