# DR-041  接線缺口為第四例；§2.9 由建議升格為必須
date: 2026-08-24    status: ACTIVE
context:  G4 準備時發現 run_exp2.Ctx.q0 = zeros(512) 且 use_query=False 為填零實作，
          僅開啟開關會得到位元相同的輸入，G4 將產生構造性 null。
          此為同一家族第四例（group-KD 無作用空間、q_tau 環境冗餘、
          group L_sem 未實作、本次 q_tau 未接線），四次皆非 PI/Fable 發現。
options:  (a) 維持 §2.9 為建議 (b) 升格為必須，未通過者實驗不得啟動
          ※ 本行由 Cursor 補上，PI 未原文指定選項清單
ruling:   §2.9 的機制生效性檢查由「寫作前一次性完成」升格為
          「任何以某機制為變因的實驗，啟動前必須先做該機制的生效性實測，
          並將結果落成產物」。未通過者該實驗不得啟動。
          四例的失效模式分屬架構、環境、實作、接線四層，
          CLAIMS C-26 的分類表補上第四層。
evidence: outputs/exp2/arch/noop_check.json；DR-040
