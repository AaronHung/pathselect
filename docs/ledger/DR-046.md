          是否照准；(2) `report_dr046.py` 的 Utility Retention 欄不可讀。

ruling:   **裁定一（先例記錄）**：tests 內的 `StackedLoRALinear` **照准**，
          維持測試專用、不進 `selector/`。

            先例：**為驗證命題自建測試對照組 ＝ 允許；
                   變更 production 行為 ＝ 必須先停工詢問。**

          Phase 0 的情況屬前者：`selector/lora.py` 只有 merge-and-reset 一種模式，
          frozen-stack 是為了證明兩者等價而造的對照組，不改變主方法任何行為。

          **裁定二（指標改版）**：`report_dr046.py` 的 **Utility Retention 比值欄移除**，
          改為 **ΔUtility = 各舊 task 的 (U_final − U_own) 平均**（越高越好，
          負值 = 退化）。理由：`utility_total` **會變號**（A1 的 esca 由 +22.0
          掉到 −42.5），比值因此可能為負或絕對值極大，不是有界的保留率，
          放在同一張表上會被誤讀為百分比。差值沒有這個問題。
          同時：腳本改為**自動納入 per_slide 內實際存在的所有臂**（並提供
          `--arms` 參數），**不得寫死清單**。

          ⚠️ 分支政策：PI 決定不用分支，Phase A 起全部直接做在 main。
          Phase 0 的 `dr046-cl-ablation` 已 fast-forward 合併並刪除，
          打 tag `dr046-phase0`。
