# DR-045  G1 退化率的兩個口徑（88.6% 與 84.5% 都對）
date: 2026-08-26    status: ACTIVE
context:   RESULTS_DOSSIER §7-⑨ 指出：**84.5%** 可從 `HIER.md` 的分佈表算出
           （1179/1395），而 **88.6%** 出現在 CLAIMS C-02、憲法 §3.6b、
           `report_prior.py`、`tests/test_report_scripts.py`，但 repo 裡沒有任何
           產物寫著 88.6 —— 疑似無依據。
options:   (a) 統一為 84.5% 並附算式 (b) 重算出 88.6% 的口徑並補產物 (c) 兩者並存但不說明
           ※ 本行由 Cursor 補上，PI 未原文指定選項清單
ruling:    (b)。88.6% **重算得出**，不是無依據的數字：

           | 口徑 | 單組 / 全部 | 比例 |
           |---|---|---|
           | 全部 arm、學完 T4 後 | 3708 / 4185 | **88.6%** |
           | 只算 A5、學完 T4 後 | 1179 / 1395 | **84.5%** |
           | 只算 A3、學完 T4 後 | 1249 / 1395 | 89.5% |
           | 只算 A5nG、學完 T4 後 | 1280 / 1395 | 91.8% |

           **兩者都對，差在範圍**：88.6% 是三個 arm 合併，84.5% 只有 A5。
           `HIER.md` 的結構性診斷表報的是 A5（共 1395 張），所以是 84.5%。

           處置：不統一成單一數字（那會刪掉真實資訊），改為**引用時必須寫明口徑**。
           已在 CLAIMS C-02、憲法 §3.6b、`report_prior.py`、
           `tests/test_report_scripts.py` 四處註明，並補產物
           `outputs/exp2/hier/DEGENERACY_RATES.md`（由 `scripts/degeneracy_rates.py` 產生）。
           ⚠️ 不論用哪個口徑，G1 的結論不變：per_chunk 在 c=1 下退化，測到的不是階層。
