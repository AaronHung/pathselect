# DR-024  跨批次配對與撤回程序入憲
date: 2026-08-25    status: ACTIVE
context:   撰寫順序依賴報告時發現先前回報的「A2 在 main 有效、reverse 無效」是錯的：
           那是共同子集（seeds 0-2）與全 5 seeds 不一致造成的假象，該錯誤已進入
           PI 的 H-SERIES 指示。
options:   (a) 只在該報告更正 (b) 更正並把兩條規則升格入憲
ruling:    (b)。§1.3 跨批次配對：seed 數不同時只能用共同子集，但必須同時檢查各自
           批次的全 seeds，不一致時以全 seeds 為準並揭露差異。§2.4 撤回程序：
           發現先前結論有誤時主動撤回、說明查證方式、附方法學教訓 ——
           撤回不算失分，隱瞞才算。順序依賴一節據此改寫：唯一乾淨的翻轉是
           A5 − A4；A5 − A3 標為「reverse 有效、main 無效」而非翻轉；
           A3 − A1 跨順序穩定，正面陳述。
evidence:  outputs/exp2/ORDER_DEPENDENCE.md；docs/CONSTITUTION.md §1.3、§2.4
