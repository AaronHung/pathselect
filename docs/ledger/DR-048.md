### B4　指標（`sota/metrics.py`）

| 指標 | 來源 | 可信度 |
|---|---|---|
| ACC | 官方 `manager/manager.py`：`average_test_acc = sum_test_acc / len(dataset_names)` | **核對過** |
| Masked ACC | 官方 `_eval_masked_metrics`：`y_hat[:, label_shift : label_shift + subtype_num]` | **核對過** |
| Forgetting / BWT | 論文只引 (Lopez-Paz & Ranzato 2017; Hayes 2018; Fini 2022)，**沒有印公式**；官方 repo 只記錄 forgetting 的**過程**，沒算純量 | **推得的** |

推導依據：從論文表中抽出 **28 組 (Forgetting, BWT)**，
**每一組都滿足 `Forgetting ≥ |BWT|`，零反例**；多數恰好相等，
少數明顯分離（最極端 0.058 vs −0.021）。這是下面這組式子的指紋 ——
兩者只差在基準點：

    BWT        = mean_{j<T−1} ( A[T−1][j] − A[j][j] )
    Forgetting = mean_{j<T−1} ( max_{l∈[j,T−2]} A[l][j] − A[T−1][j] )

故恆有 `Forgetting ≥ −BWT`，並在「學完任務 j 之後準確率還會再上升」時分離。
這同時**否證**了「Forgetting 直接定義為 −BWT」的簡化讀法。
⚠️ 這是推論，不是引用。取得作者公式或原始碼後須回來核對。

我們的真實資料**確實落在兩式分離的區間**（A5 seed0：task 0 的峰值在 stage 1 的
0.8667 而非 stage 0 的 0.8000 → Forgetting 0.0762 ≠ −BWT 0.0452），
所以兩個欄位不是重複的。`tests/test_sota_metrics.py` 把這件事釘成測試。

### B6　OPCM-Merge (adapted)

出處：Bui et al., *MergeSlide*, arXiv:2511.13099（WACV 2026），Eq. (3)–(5)；
官方實作 `caodoanh2001/MergeSlide::opcm_mergeslide.py`。
**重新實作，未移植任何一行程式碼。**

**⚠️ 發現一：官方程式的零對角遮罩是 no-op。**
它寫 `projected_task_tv.diag().fill_(0)`，但 `Tensor.diag()` 對 2-D 輸入回傳
**副本**（torch 2.11 實測），不是 view —— 那一行沒有改到被投影的矩陣。
少了遮罩，full SVD 下 `U (Uᵀ Δθ_t V) Vᵀ ≡ Δθ_t`（實測誤差 9e-7），
`G(·)` 退化成恆等，`merge_linear_weights` 與 `merge_other_parameters` 完全相同 ——
**亦即官方跑出來的是「直接相加」，不是論文描述的正交投影。**
本檔照**論文**實作（用 `.diagonal()`，實測 ⟨G, Δθ̃⟩_F ≈ 0 成立），
並提供 `--no-mask` 重現官方行為。兩者 `tests/test_sota_opcm.py` 都釘住。

**⚠️ 發現二：λ 的分母，論文寫 `‖θ_i‖₂`，官方程式用 `‖θ_i − θ_base‖₂`**
（`get_task_vector_norm`）。本檔照**程式** —— `‖θ_i‖₂` 含未微調的基礎模型本身、
量級由 θ_base 主導，會讓 λ 幾乎不隨任務變化，顯然不是原意。
λ 是**全域純量**（整份 state dict 攤平後取範數），不是逐矩陣算，同樣照程式。

**接法**：θ_base = θ₀，θ_t = θ₀ + Δ_t，Δ_t 直接取自 C1／C2 已算好的
`outputs/exp2/main/dr046_deltas_seed{seed}.pt`（每任務各自從同一個 θ₀ bare 訓練），
正是 OPCM 假設的輸入。⚠️ 因此 OPCM 只在 **fold 1、seed 0–4（DR-046 協定）** 存在，
不是 SOTA 主表的 10 折 —— `docs/SOTA_TABLE.md` 逐列標明。

### B6　zero-shot 參照線
`meanpool`（全部 patch 等權）與 `rand8`（隨機 B 個，與主線同預算），共用凍結的
CONCH 頭，**沒有可訓練參數** → 跨 stage 完全不變，Forgetting 與 BWT 必然為 0。
這不是「不遺忘的好方法」而是「沒有東西可遺忘」，表中標成參照線而非 CL 方法。
冒煙實測 Forgetting = 0.000，符合預期。
