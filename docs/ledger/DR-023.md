# DR-023  n<5 批次的統計警語升格為憲法條文
date: 2026-08-25    status: ACTIVE
context:   三級 win count 規則（DR-020）是以 n=5 校準；但 main order、元件消融、
           E3 都只有 3 seeds，直接套用同一組標籤會高估信心（3/3 被標成 systematic）。
options:   (a) 只在該批報告加註 (b) 升格為跨實驗的統計政策並自動加註
           (c) 為 n<5 另訂一套門檻
ruling:    (b)。n<5 的批次一律加註「本批的 systematic 應讀作方向一致而非已定案；
           寫進論文的主張必須回到 5-seed 確認」，由報告產生器自動輸出、不依賴人工
           記得。不另訂門檻 —— 多一套門檻只會製造混淆，正確做法是補足 seeds。
           規則本體移入 docs/CONSTITUTION.md §1.2，DR 卡只留來源。
