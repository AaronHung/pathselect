# DR-030  回報內容必須存在於 committed 產物中
date: 2026-08-23    status: ACTIVE
context:   8/23 的 G1 回報貼出結構性診斷表（84.5% 單組），數字有效，但因 replace
           錨點失效而從未寫入 HIER.md。回報與磁碟產物不一致，PI 據此下達過裁定。
options:   (a) 只修該次 (b) 立規則：回報內容必須先存在於 committed 產物
ruling:    (b)。任何寫進回報的表格或數字，必須同時存在於 committed 的產物檔中。
           回報前確認該檔含該內容；臨時 python 算出的數字必須**先寫進產物再回報**。
           憲法 §2.8 收錄。
evidence:  report_hier.py 的 diag 區塊缺失（8/23 追查）；docs/CONSTITUTION.md §2.8
