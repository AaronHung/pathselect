# DR-054  累積式頭下的合規 hinge：replay 時以當前 C_t 由快照 P_old 重算 U_old
date: 2026-09-15    status: ACTIVE
context:   DR-053 證明：累積式頭下，hinge 以快照時的 C_old 量 U_old／U_new，只保住舊類別
           內部的鑑別力，對「舊證據是否仍能與後加類別分開」沒有約束，B2 class-IL 因此
           掉 13.8 pp、A5 掉 5.3 pp（同平台 pod）。把 hinge 改成全 8 類即回到 80.97，
           但那用到快照時未見類別的文字嵌入，不合規。PI 於 Prompt 23-B 立案：
           **replay 時以當前 C_t 重算 U_old**（由快照的 P_old 等權池化），與 U_new
           同口徑、不用未見類別、不改快照 schema；先 fold-1 五 seed，過門檻才十折。
options:   (a) 存快照時預存多組 U_old（每個未來 C_t 一份）—— 需未見類別，不合規
           (b) replay 時重算：`continual_terms` 已重載 Z，由 `selected_from_entry`
               取回 P_old，等權池化 → frozen head → 遮罩到**當前** C_t → U_old(C_t)
ruling:    **(b)**，以 `--uold current` 開關實作（預設 `snapshot` = DR-052 現行路徑，
           逐位元不變；固定頭下兩種模式的 U_old 數值上相同，因為快照的 u_old 就是
           telescoped 的 log 8 − CE_uniform(P_old)）。

           ## 定義（`--head accumulating --uold current`）

           replay 步驟取回 entry（任務 τ）後：
           * P_old = `selected_from_entry(entry, B)`（快照候選中 s_old 最高的 B 個）
           * U_old(C_t) = log|C_t| − CE(mask_{C_t}(head_uniform(P_old)), y)，不帶梯度
           * U_new(C_t) = log|C_t| − CE(mask_{C_t}(head_uniform(P_new)), y)
           * L_eq = max(0, U_old(C_t) − U_new(C_t))
           快照的 `u_old`／`class_mask_old` 欄位在此模式下不被讀取；schema 不變。
           L_diag、L_sem、u_i teacher、replay CE、評估全部照 DR-052 的累積式頭。

           ## 測試（實作前列出）

           1. `--uold snapshot`（預設）：`continual_terms` 與 DR-052 路徑逐位元相同
              （同輸入同輸出；既有 pytest 全過）。
           2. `current` 模式：合成 entry 下，U_old == 獨立算的 log|C_t| − CE_uniform(P_old)
              （容差 1e-6）；未見類（C_t 外）logit 任意改動不影響 U_old 與 U_new。
           3. 固定頭（mask=None）下 `current` 與 `snapshot` 的 U_old 相等（容差 1e-5）。
           4. 注入路徑：`run_exp2 --uold current` 的 per_slide 紀錄帶 `uold: "current"`。
